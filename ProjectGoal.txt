 --- Project Goal ---
	This project is meant to showcase how one might go about setting up a series of Microservices 
	that work independently or in conjunction to simulate functionality of real world: Microservices, API Gateway, Load Balancing, Authentication, and Logging.

	For Added Measure I will be creating services, the most generic/common example(s) I can think of, which will entail the following:
		- User's: Simulating generic user information (Username, POC information, etc.)
		- Warehouse: Simulating goods that are sold, moved, and stored within. (item_id, name, cost, location, quantity_in_stock, quantity_ordered, quantity_on_backorder, etc.)
		- Logging (event, occurred_on, service, etc)

	This will also include Database logic including: Creation, Stored Proceedures, and Overall Design/Functionality individually for each Microservice.

	To ensure that each of the services and features are working as intended, I will be implementing a series of Unit Tests for each service individually and an overarching
	Test for all microservices when working in conjunction with one another.

	I will also be implementing an API Gateway to route requests to the appropriate Microservice. This will include:
		- Load Balancing between multiple instances of the same Microservice.
		- Authentication and Authorization for the API Gateway and Microservices.
		- Logging and Monitoring for the API Gateway and subsequent Microservices.

	Lastly, I will be implementing several DevOps features to ensure that the project is easily deployable and maintainable. This will include:
		- Dockerization of each Microservice
		- Dockerization of the API Gateway
		- Dockerization of the Database(s)
		- Docker Compose to bring up all services together for testing and deployment.
		- CI/CD Pipeline for automated testing and deployment.

	- Completion Benchmarks -
	This project would be considered complete when the following goals have been met:
		- A series of Microservices that can be deployed independently or together.
			- User Service
				- User information and manipulation through API Functionality to maintain and update the User DB. 
			- Warehouse Service
				- Data manipulation through API Functionality for the Warehouse DB to simulate sales and inventory management.
			- Logging Service
				- Data manipulation through API Functionality for the transactional activities that occur on all other services.
		- An API Gateway that can route requests to the appropriate Microservice.
		- Load Balancing between multiple instances of the same Microservice is possible/testable.
		- Authentication and Authorization for the API Gateway and Microservices is possible/testable.
		- Logging and Monitoring for the API Gateway and subsequent Microservices is possible/testable.
